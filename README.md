# Custom Modular Electric One-Wheeled Skateboard

Custom one-wheeled electric skateboard, inspired by the iconic Onewheel but reimagined with modularity and repairability in mind. This design features a tool-free removable battery module, TPU swappable bumpers, and a chain-driven drivetrain
